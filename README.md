# Android Battery Logger

Android 17 (API 37) 向けの個人用端末状態ロガーです。監視はユーザーが開始し、アプリ専用領域の日別 CSV に記録します。V1.0 ではネットワーク送信を行いません。

## 現在の実装

- 監視開始時の即時サンプルと、約 60 秒ごとのベストエフォート記録
- バッテリー、画面、輝度、メモリ、Wi-Fi、モバイル回線、利用中アプリの取得
- 単調時計を基準にした測定予約と、ネットワーク状態変更コールバックのキャッシュ
- Foreground Service の常駐通知からの停止操作
- 10 分ごと、日付変更時、停止時の CSV 保存
- 欠測理由・権限状態を含む CSV 記録
- 日付を選び、システムのファイル作成画面から任意の日の CSV を書き出し
- CSV schema 1.1。過去の列構成が異なる日別ファイルは分離して保持

利用中アプリ、Wi-Fi SSID、モバイル回線の項目は、対応する権限を許可した場合だけ記録します。監視周期は OS の省電力制御によって遅れることがあります。

## ビルド

Android Studio でこのディレクトリを開き、Android SDK Platform 37、AGP 9.3.1、Gradle 9.5.0、JDK 17 を利用してください。対象 OS は Android 17/API 37 です。
