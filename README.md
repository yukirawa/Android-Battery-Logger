# Android Battery Logger

Android 17 (API 37) 向けの個人用端末状態ロガーです。監視はユーザーが開始し、アプリ専用領域の日別 CSV に記録します。V1.0 ではネットワーク送信を行いません。

## 実装方針

- 監視開始時に測定し、その後は約 60 秒を目安に記録
- バッテリー、画面、メモリ、通信、利用中アプリを可能な範囲で取得
- Foreground Service の常駐通知から停止可能
- UTF-8 の日別 CSV を端末内に保存し、ユーザー操作で書き出す
- 権限不足や非対応項目は欠損値と状態列で区別

利用中アプリ、Wi-Fi SSID、モバイル回線の項目は、対応する権限を許可した場合だけ記録します。監視周期は OS の省電力制御によって遅れることがあります。

## ビルド

Android Studio でこのディレクトリを開き、Android SDK Platform 37 と JDK 17 以降を利用してください。対象 OS は Android 17/API 37 です。
